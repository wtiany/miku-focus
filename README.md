# 初音未来专注 · 使用入口

平时只需要使用下面两个文件：

- **[index.html](index.html)**：双击打开，使用单人计时、待办、背景设置和本地音乐，不需要启动服务。
- **[启动学习房间.cmd](启动学习房间.cmd)**：需要网易云登录、歌单导入或房间功能时使用。服务就绪后会自动用默认浏览器打开网页，默认地址是 [localhost:8642](http://localhost:8642)；使用期间保持启动窗口开启。

## 文件夹怎么分

| 位置 | 内容 |
|---|---|
| `app/` | 程序代码、图片视频、依赖、配置、测试和工具，日常不用打开 |
| `docs/` | 使用说明和多人房间说明 |
| `启动工具/` | Cloudflare 临时公网分享入口 |

需要 Cloudflare 临时链接时，用 [一键分享学习房间.cmd](启动工具/一键分享学习房间.cmd)。

**请整体保留这个项目文件夹。** `index.html` 会加载 `app/` 内的文件，不要单独移动网页文件。整理保留了原网页入口路径和服务端口，浏览器内已有数据不需要迁移。

详细操作见 [完整使用说明](docs/使用说明.md)。


## 添加背景图片

点击左上角 **背景设置 → ＋ 添加背景图片**，可以多选 JPG、PNG、WebP、GIF（单张最多 20 MB）。添加后立即显示第一张，并开启自动轮播；相同图片不会重复添加。

通过本机服务打开网页时，图片会复制到 `app/assets/images`，原文件保留；索引写入同目录的 `custom-backgrounds.js`，刷新、重启服务或直接打开 HTML 都能继续使用。自选图片及索引仅在本机保存，已由 Git 忽略，不会随源码推送；手动分享整个文件夹时仍会包含它们。项目写入只能由服务电脑本机操作。

直接双击 HTML 时，图片保存在当前浏览器的 IndexedDB，刷新后可恢复，但不会复制到项目文件夹；如需复制进项目，请使用 **启动学习房间.cmd**。远程 HTTPS 页面也只保存在当前浏览器。

## 音乐库与播放列表

底部的**歌曲管理按钮（文件夹音符）**打开音乐库，按「本地导入」和网易云歌单原名分组。点 **＋** 导入只会保存到音乐库，重复导入同一歌单会合并歌曲。

- **播放整张歌单**：用选中的歌单替换底部播放列表，并从第一首开始播放。
- **＋ 加入列表**：把某首歌追加到播放列表，保留当前歌曲的播放进度。
- 已加入的歌曲显示 **从列表移除**，点击只移出播放队列，音乐库收藏保留。
- 歌曲管理中可以搜索当前歌单的**歌名或歌手**，支持多个关键词与英文大小写；「清空」恢复全部歌曲。搜索只筛选显示，「播放整张歌单」仍播放完整歌单。
- 底部**列表按钮（三条横线）**查看待播放歌曲，右侧滚动条可拖动；点列表外的空白处收起，操作按钮和音量等控件时保持打开。移除或清空只改变播放列表，音乐库仍保留。
- 音乐库中可**删除歌单**或点击歌曲旁的**垃圾桶**移除单首歌曲，确认后生效；没有其他歌单收藏的歌曲也会移出播放列表。本地来源使用「清空本地导入」，只删除网页保存的副本，不动电脑原文件。这些操作不修改网易云账号里的原歌单。

音乐库与播放列表会在当前浏览器中记忆，会员歌曲也保留歌名、分组和播放列表位置，播放时按当前账号权限检查，无需每次重新导入。旧版歌曲自动归入「本地导入」或「以前导入的网易云音乐」；旧版没有保存网易云歌单名，重新导入原歌单后即可按原名收藏。

## 记住网易云登录

Windows 下，在 **＋ → 记住本浏览器的登录** 保持勾选，再扫码并在手机确认。下次使用同一 Windows 用户、浏览器和网址启动时，会验证并尝试恢复登录，最长记住 30 天；平台使登录失效时需重新扫码。已登录时也可直接勾选，无需再扫码。

凭证由 Windows DPAPI 加密保存在 `%LOCALAPPDATA%\MikuFocus\auth\netease-sessions.dpapi`，位于项目文件夹之外；浏览器只持有 HttpOnly 的随机会话标识。点「退出登录」或取消「记住登录」会移除对应的保存记录；退出同时停止会员歌曲，收藏保留。临时公网域名更换、清除 Cookie 或换浏览器后需重新登录。非 Windows 环境继续支持本次服务内登录。

## 开发命令

在项目根目录运行：

```powershell
npm --prefix app start
npm --prefix app test
npm --prefix app run test:personal
npm --prefix app run test:music
npm --prefix app run test:remember
npm --prefix app run test:backgrounds
npm --prefix app run test:browser
```

本机配置位于 `app/.env`（示例是 `app/.env.example`）。Docker 构建在根目录执行 `docker build -f app/Dockerfile -t miku-focus .`。
