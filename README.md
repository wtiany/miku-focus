# 初音未来专注 · Miku Focus

一个初音未来主题的**专注学习页面**：全屏初音大图陪伴 + 计时器 + 本地音乐播放器。单人模式为纯本地网页，无需安装、无需服务器、无需联网，双击即用；可选的多人房间需要另行启动服务。

![主题](assets/images/miku_guitar_night.jpg)

## 快速开始

> **多人学习房间：一键临时 HTTPS 分享**。双击 `一键分享学习房间.cmd`，等自动打开页面后创建房间、复制邀请，朋友点链接即可加入，无需账号、域名或 TURN 配置。支持最多 6 人共同添加歌曲、控制播放、刷新恢复与房主转移；房间音乐会临时上传到运行服务的电脑。保持电脑与启动窗口开启，详见 [多人房间说明.md](多人房间说明.md)。原来的离线单人模式仍然可用。

**双击 `index.html`** 用 Chrome 或 Edge 打开即可（推荐这两种浏览器，Firefox 下歌单记忆功能受限，见文末）。

需要网易云导入或多人房间时，双击 `启动学习房间.cmd`，或在项目目录运行：

```bash
cd 项目目录
npm start
# 浏览器打开 http://127.0.0.1:8642/
```


## 功能一览

### 🖼 全屏壁纸舞台（页面主体）
- 5 组壁纸全屏轮播：3 张插画 + 2 段动态视频，**全部来自你自己的 Wallpaper Engine 素材**；已移除播放卡顿的 Project G 围巾初音视频。
- 学习与休息共用同一组轮播：插画每 30 秒淡入淡出切换，视频按自身时长播完一整遍再换下一项（列表里只有一个视频时无缝循环）
- **想换想加**：mp4 / webm 视频或图片放进 `待换图片\` 文件夹（没有就新建一个）说一声即可，全屏静音循环播放
- 点击画面任意位置手动切换（不点也会自动轮换）
- **浏览器全屏**：点击左上角“进入全屏”，隐藏浏览器标签栏、地址栏及任务栏；按钮随之变为“退出全屏”，也可以按 **Esc** 退出。全屏开关在沉浸模式下仍保留。
- **沉浸模式**：按 **I** 键收起操作区与其他悬浮模块，保留时长、进度条和全屏开关；鼠标一动即恢复
- 漂浮音符点缀（尊重系统的"减少动态效果"设置）
- 若刷新后视频没有自动播放，点一下页面任意处即可开始（浏览器自动播放策略）

### ⏱ 专注计时（右上小模块）
- **开始学习**后正计时；**暂停**冻结时间，**继续**接着走（暂停时间不计入专注时长）
- **计时卡自动收起**：学习时鼠标移开只保留时长与进度条，靠近即展开；点时长可固定展开，再点、点外部或按 Esc 收起。暂停和休息时自动展开，触屏也可点时长操作。
- **休息一会**：3 / 5 / 10 / 15 分钟倒计时（计时模块切换为暖色主题，壁纸不变）；可**跳过休息**，倒计时结束自动回到学习并显示文字提示
- 专注目标可选 25 / 45 / 60 / 90 分钟，细进度条实时显示进度，**达标会有提示**
- **结束**弹出本次总结（专注时长、休息次数、今日累计），按 **回车** 或点按钮关闭
- **刷新/意外关闭不丢进度**：未结束的计时会自动接续（按墙上时间继续算）；跨午夜的专注段在统计里按天拆分归属
- 快捷键：**空格键 = 开始 / 暂停 / 继续**
- 连续学习每满 **50 分钟**会弹一条提示建议休息（提醒间隔可在 `app.js` 顶部 `SIT_REMIND_MS` 修改，暂停不计时、休息后重新算）
- 计时卡底部显示**今日累计专注**与**完成段数**（按日期自动归零，数据存在本机浏览器）

### 🎧 专注歌单（底部细条播放器）
- 点 **＋** 打开音乐导入，支持粘贴网易云公开歌单链接，或点「选择本地文件」导入 mp3 / m4a / aac / flac / wav / ogg / opus（可一次多选）
- **网易云歌单**：公开音源免登录；可选扫码登录后按自己的账号权限检查歌单和音源，只导入可完整播放的歌曲。单次最多检查 200 首；支持单人列表和多人共享歌单，并自动去重，无需额外 API 服务。
- 上一首 / 播放暂停 / 下一首 / 点击列表播放 / 拖动进度条 / 音量调节
- **播放模式**：点播放模式按钮在**顺序循环 / 单曲循环 / 随机播放**间循环切换，选择会被记住（随机模式不会连续重复同一首）
- 一首播完按当前模式自动接续；点 **列表按钮** 展开，每首可单独移除
- **音乐渐变**：暂停/结束学习时音乐约 2.5 秒缓降归零后停止，恢复学习自动淡入回原音量，不再生硬切断
- **歌单自动记忆**：本地音频保存在浏览器 IndexedDB，单人网易云公开音源的歌曲信息保存在 localStorage；刷新后恢复。需要账号权限的曲目仅留在当前页面，退出登录时移除。在线曲目仍需网络访问网易云，不缓存音频文件。
- 音量设置也会被记住

### ✅ 待办事项（左缘收纳栏）
- 平时完全隐藏，鼠标移到屏幕左缘的 **✓ 把手**上即滑出（点击把手可钉住/收起）
- 输入文字回车或点 **＋** 添加；**点击条目**打勾划掉（再点恢复）；**✕** 删除
- **拖动条目**调整顺序（按住即可拖）
- 把手上的数字徽章 = 未完成数量，面板标题旁显示 完成数/总数
- 待办保存在浏览器本地，下次打开还在

## 音乐文件从哪来

可直接在「＋」中粘贴网易云歌单链接或歌单 ID，点「读取歌单」，检查可播放数量后导入。需要登录时，点「扫码登录」，用网易云音乐手机 App 扫码并确认，再重新读取歌单。无需输入密码或手动复制 Cookie；无权限的歌曲与试听片段不会作为完整歌曲导入，也不尝试歌曲解锁。

登录只对当前浏览器和当前网站地址生效。房间成员分别扫码，使用各自的账号权限；共享歌单不会把导入者的登录凭证或专属音源地址广播给朋友。导入到房间的歌名会对成员可见。点「退出登录」会停止本页面的账号歌曲，并清除服务端会话；其他同站标签页会同步退出。服务重启、临时链接更换或登录失效后需重新扫码。

如果手机已确认但网易云返回 **8821**，页面会停止重试并显示平台拒绝提示。可先在网易云官网完成官方登录与必要的安全验证；这不会自动把官网登录状态同步到本项目，也不保证平台会允许下一次扫码。不要将 Cookie 或密码发送到聊天中。

也可以选择自己已有的标准音频文件。网易云客户端下载若是 `.ncm` 等浏览器不支持的格式，不能直接作为本地音频导入。


## 数据与隐私

离线单人模式下，所有数据**只存在你自己的浏览器里**，不联网上传。主动导入网易云歌单时，服务会向网易云请求歌单与歌曲资料，并检查音源；播放时浏览器直接向网易云音频 CDN 加载音乐。主动扫码后，平台登录凭证仅存运行服务的电脑内存，按浏览器隔离，不写文件、localStorage 或房间消息。浏览器仅持有 HttpOnly、SameSite 的随机会话 Cookie；HTTPS 下启用 Secure。退出、服务停止或连续 12 小时无会话请求后清除登录（超时在下次请求时检查）。请仅在你信任的房间服务上扫码。

多人房间会向房间服务发送昵称、学习状态、本段时长、共享歌单和临时本地音频文件，供成员共同收听。房间结束或全员离线约 30 分钟后清理上传音频；网易云曲目只共享歌曲信息和播放状态。待办、个人历史和单人音乐库不自动上传。一键分享使用 Cloudflare 隧道代理访问，详情见 [多人房间说明.md](多人房间说明.md)。单人数据存储如下：

| 数据 | 存储位置 | 清除方式 |
|---|---|---|
| 导入的音乐文件 | IndexedDB 库 `mikuFocusDB` | 播放列表里点 ✕，或清除浏览器站点数据 |
| 单人网易云列表 / 最近输入的歌单链接 | localStorage `mikuFocusNetease_v1` / `mikuFocusNeteaseLink` | 移除歌曲 / 清除浏览器站点数据 |
| 待办事项 | localStorage 键 `mikuFocusTodos_v1` | 待办面板里逐条 ✕，或清除浏览器站点数据 |
| 未结束的计时快照 | localStorage 键 `mikuFocusRun_v1` | 计时段结束后自动清除 |
| 每日专注统计 | localStorage 键 `mikuFocusStats_v1` | 同上 |
| 音量设置 | localStorage 键 `mikuFocusVol` | 同上 |


## 常见问题

- **刷新后歌单还在吗？** 在。Chrome/Edge 下自动恢复；Firefox 打开本地文件（file://）时数据库受限，会自动退回"仅本次会话有效"，其余功能不受影响。
- **换电脑/换浏览器后歌单和统计没了？** 这些数据按浏览器存储，不跟随文件，需要重新导入。
- **素材版权**：壁纸插画与视频均来自你自己的 Wallpaper Engine 素材（工程包 / 订阅内容提取），仅供个人本地使用，请勿商用或二次分发。
