# 初音未来专注 · Miku Focus

> 日常入口在项目根目录；分享脚本位于 `启动工具/`，程序、测试和 `.env` 配置位于 `app/`。以下命令在项目根目录执行。

一个初音未来主题的**专注学习页面**：全屏初音大图陪伴 + 计时器 + 本地音乐播放器。单人模式为纯本地网页，无需安装、无需服务器、无需联网，双击即用；可选的多人房间需要另行启动服务。

![主题](../app/assets/images/miku_guitar_night.jpg)

## 快速开始

> **多人学习房间：一键临时 HTTPS 分享**。双击 `一键分享学习房间.cmd`，等自动打开页面后创建房间、复制邀请，朋友点链接即可加入，无需账号、域名或 TURN 配置。支持最多 6 人共同添加歌曲、控制播放、刷新恢复与房主转移；房间音乐会临时上传到运行服务的电脑。保持电脑与启动窗口开启，详见 [多人房间说明.md](多人房间说明.md)。原来的离线单人模式仍然可用。

**双击 `index.html`** 用 Chrome 或 Edge 打开即可（推荐这两种浏览器，Firefox 下歌单记忆功能受限，见文末）。

需要网易云导入或多人房间时，双击 `启动学习房间.cmd`，或在项目目录运行：

```bash
# 先进入解压后的项目文件夹
npm --prefix app start
# 浏览器打开 http://127.0.0.1:8642/
```

普通 `python -m http.server` 仅提供静态单人页面，不支持网易云接口和多人房间。

## 功能一览

### 🖼 全屏壁纸舞台（页面主体）
- 5 组壁纸全屏轮播：3 张插画 + 2 段动态视频。
- 学习与休息共用同一组轮播：插画每 30 秒淡入淡出切换，视频按自身时长播完一整遍再换下一项（列表里只有一个视频时无缝循环）
- 点击画面任意位置手动切换（不点也会自动轮换）
- **背景设置**：左上角可直接选择主题；选择后固定该背景，也可打开「自动轮换」。开启「省性能模式」后仅使用静态图片，停止视频加载、播放和背景动效。选择与开关会保存在当前浏览器，刷新后保留。
- **添加背景图片**：点「背景设置 → ＋ 添加背景图片」选择电脑中的 JPG、PNG、WebP 或 GIF，可以一次多选，每张最多 20 MB。会立即显示第一张并开启轮播；同一张自选图片按内容去重，损坏图片会提示跳过。
- **保存位置**：通过服务电脑的本机网页操作时，原图会复制到 `app/assets/images/custom-<内容摘要>.<格式>`，图片名称和轮播索引写入 `custom-backgrounds.js`，不移动原文件。刷新、重启和直接打开 HTML 后仍可读取。自选图片及索引已由 Git 忽略，不随源码推送；手动分享整个文件夹时仍会包含它们。在离线 HTML 或远程 HTTPS 页面添加，则保存在当前浏览器的 IndexedDB，不能直接写入服务电脑的项目文件夹。普通远程 HTTP 页面请换用 HTTPS 或服务电脑的 localhost 地址。
- **浏览器全屏**：点击左上角“进入全屏”，隐藏浏览器标签栏、地址栏及任务栏；按钮随之变为“退出全屏”，也可以按 **Esc** 退出。全屏开关在沉浸模式下仍保留。
- **沉浸模式**：按 **I** 键收起操作区与其他悬浮模块，保留时长、进度条和全屏开关；鼠标一动即恢复
- 漂浮音符点缀（尊重系统的"减少动态效果"设置）
- 若刷新后视频没有自动播放，点一下页面任意处即可开始（浏览器自动播放策略）

### ⏱ 专注计时（右上小模块）
- **开始学习**后正计时；**暂停**冻结时间，**继续**接着走（暂停时间不计入专注时长）
- **计时卡自动收起**：学习时鼠标移开只保留时长与进度条，靠近即展开；点时长可固定展开，再点、点外部或按 Esc 收起。暂停和休息时自动展开，触屏也可点时长操作。
- **休息一会**：3 / 5 / 10 / 15 分钟倒计时（计时模块切换为暖色主题，壁纸不变）；可**跳过休息**，倒计时结束自动回到学习并显示文字提示
- 专注目标可选 25 / 45 / 60 / 90 分钟，细进度条实时显示进度，**达标会有提示**
- **结束**弹出本次总结（专注时长、休息次数、今日累计），按 **回车** 或点按钮关闭
- **刷新/意外关闭不丢进度**：未结束的计时会自动接续（按墙上时间继续算）；跨午夜的专注段在统计里按天拆分归属
- 快捷键：**空格键 = 开始 / 暂停 / 继续**
- 连续学习每满 **50 分钟**会弹一条提示建议休息（提醒间隔可在 `app.js` 顶部 `SIT_REMIND_MS` 修改，暂停不计时、休息后重新算）
- 计时卡底部显示**今日累计专注**与**完成段数**（按日期自动归零，数据存在本机浏览器）

### 🎧 我的音乐库与播放列表
- 点 **＋** 打开音乐导入，支持粘贴网易云公开歌单链接，或点「选择本地文件」导入 mp3 / m4a / aac / flac / wav / ogg / opus（可一次多选）
- 点底部 **歌曲管理按钮（文件夹音符）** 打开音乐库：本地文件归入「本地导入」，网易云歌单按原名分别收藏。导入完成只保存到音乐库，不会自动加入底部播放列表。
- **播放整张歌单**：替换当前播放列表，从第一首开始播放。**＋ 加入列表**：追加一首歌曲，保留当前播放进度；已在列表中的歌曲显示「从列表移除」，点击只移出队列，音乐库收藏保留。移除当前播放的歌曲会继续播放下一首，移除最后一首则停止。
- **搜索歌曲**：在歌单内输入歌名或歌手，即时筛选；支持英文大小写、全角字符和多个空格分隔关键词。显示匹配数量，点「清空」恢复全部；在搜索框按 Esc 先清空，再按 Esc 关闭弹窗。切换来源时可继续用同一关键词查找，重新打开管理会清空搜索。搜索不会改变收藏或播放队列，「播放整张歌单」仍使用完整歌单。
- 同一网易云歌单重复导入会合并新增歌曲、更新歌单名；不同来源歌单可以收藏同一首歌曲。相同文件名、大小和修改时间的本地文件会跳过重复导入。
- **网易云歌单**：公开音源免登录；可选扫码登录后按自己的账号权限检查歌单和音源，只导入可完整播放的歌曲。单次最多检查 200 首；支持单人列表和多人共享歌单，并自动去重，无需额外 API 服务。
- 上一首 / 播放暂停 / 下一首 / 点击列表播放 / 拖动进度条 / 音量调节
- **播放模式**：点播放模式按钮在**顺序循环 / 单曲循环 / 随机播放**间循环切换，选择会被记住（随机模式不会连续重复同一首）
- 一首播完按当前模式自动接续；点 **列表按钮（三条横线）** 展开待播放歌曲，列表最高 520px，窄屏或矮屏会自动适配；播放/暂停时保留列表滚动位置。右侧滚动条加宽为 12px，方便拖动；点列表外的空白处收起，按钮、音量和进度条仍可直接操作。列表打开时点背景只收起列表，再点才按原设置切换背景。可以单独移除或清空，两种操作都只修改播放列表，音乐库收藏不受影响。
- **音乐渐变**：暂停/结束学习时音乐约 2.5 秒缓降归零后停止，恢复学习自动淡入回原音量，不再生硬切断
- **音乐库与队列分别记忆**：本地音频保存在浏览器 IndexedDB，网易云来源分组和歌曲信息保存在 localStorage；播放列表另外保存歌曲引用，刷新后恢复，清空后也不会重新塞回全部收藏。会员歌曲也保留歌名与分组，退出后停止播放，重新登录即可按权限播放，无需每次重新导入。在线曲目仍需网络访问网易云，不缓存音频文件。
- **删除收藏**：歌单标题右侧的「删除歌单」删除整个来源；每首歌旁的垃圾桶从此来源移除单首，都有确认提示。歌曲若还被其他来源歌单收藏，会继续保留；没有其他收藏时，也会移出个人播放列表，若正在播放则停止。本地来源可以逐首删除或「清空本地导入」，只删除网页保存的音频副本，保留电脑原文件。这些操作不修改网易云账号中的原歌单。
- **旧版迁移**：原有本地音乐归入「本地导入」；旧版未保存网易云歌单名，因此原有在线曲目归入「以前导入的网易云音乐」，可重新导入原歌单按原名收藏。首次迁移保留原播放列表。
- 个人音乐库不会自动上传到多人房间；房间内继续使用房间导入按钮添加共享歌曲。
- 音量设置也会被记住

### ✅ 待办事项（左缘收纳栏）
- 平时完全隐藏，鼠标移到屏幕左缘的 **✓ 把手**上即滑出（点击把手可钉住/收起）
- 输入文字回车或点 **＋** 添加；**点击条目**打勾划掉（再点恢复）；**✕** 删除
- **拖动条目**调整顺序（按住即可拖）
- 把手上的数字徽章 = 未完成数量，面板标题旁显示 完成数/总数
- 待办保存在浏览器本地，下次打开还在
- **任务计时**：开始学习前，在计时卡「本段任务」中选择待办，或点待办旁的「专注」。本段开始后关联固定，暂停和休息不计入任务时长；结束时自动累计，待办下方和结束总结可查看。刷新会恢复本段关联，已有待办内容与完成状态保留。

## 音乐文件从哪来

可直接在「＋」中粘贴网易云歌单链接或歌单 ID，点「读取歌单」，检查可播放数量后导入。需要登录时，点「扫码登录」，用网易云音乐手机 App 扫码并确认，再重新读取歌单。无需输入密码或手动复制 Cookie；无权限的歌曲与试听片段不会作为完整歌曲导入，也不尝试歌曲解锁。

Windows 下可勾选「记住本浏览器的登录」后扫码，或在已登录状态直接勾选。服务重启和浏览器重开后，使用同一 Windows 用户、浏览器和网址会验证并尝试恢复登录，最长保存 30 天。首次恢复会向网易云验证账号；网络暂时中断会保留加密记录以便稍后重试，平台确认失效时则清除登录并要求扫码。已导入的会员歌曲保留，播放时重新检查当前账号权限。

登录只对当前浏览器和网站地址生效。房间成员分别扫码，使用各自的账号权限；共享歌单不会把导入者的登录凭证或专属音源地址广播给朋友。导入到房间的歌名会对成员可见。点「退出登录」会停止本页面的会员歌曲，清除对应的已保存登录；同站其他标签页会同步退出，收藏保留。取消「记住登录」会清除保存记录，但当前服务中的登录仍可用。没有勾选、非 Windows 环境、临时域名更换、清除 Cookie、换浏览器或平台登录失效时，可能需要重新扫码。

如果手机已确认但网易云返回 **8821**，页面会停止重试并显示平台拒绝提示。可先在网易云官网完成官方登录与必要的安全验证；这不会自动把官网登录状态同步到本项目，也不保证平台会允许下一次扫码。不要将 Cookie 或密码发送到聊天中。

也可以选择自己已有的标准音频文件。网易云客户端下载若是 `.ncm` 等浏览器不支持的格式，不能直接作为本地音频导入。

网易云导入需要通过 `启动学习房间.cmd` 或 `一键分享学习房间.cmd` 打开页面；双击 HTML 的离线模式继续支持本地音乐。该功能使用平台目前可访问的网页接口和公开音源，平台接口、权限或外链变化时可能需要更新适配。

## 数据与隐私

离线单人模式下，所有数据**只存在你自己的浏览器里**，不联网上传。主动导入网易云歌单时，服务会向网易云请求歌单与歌曲资料，并检查音源；播放时浏览器直接向网易云音频 CDN 加载音乐。扫码登录按浏览器隔离：未勾选记住时，平台凭证只存服务内存，服务停止或连续 12 小时无请求后清除；Windows 勾选记住后，凭证通过当前 Windows 用户的 DPAPI 加密，写入项目目录之外的 `%LOCALAPPDATA%\MikuFocus\auth\netease-sessions.dpapi`，最长 30 天。不会写入前端 localStorage、项目文件或房间消息。浏览器只持有 HttpOnly、SameSite 的随机会话 Cookie，HTTPS 下启用 Secure；记住登录时 Cookie 有有效期。退出登录、取消记住或平台确认失效会移除保存记录。运行服务的电脑可使用已授权的登录，请仅在信任的服务上扫码。

多人房间会向房间服务发送昵称、学习状态、本段时长、共享歌单和临时本地音频文件，供成员共同收听。房间结束或全员离线约 30 分钟后清理上传音频；网易云曲目只共享歌曲信息和播放状态。待办、个人历史和单人音乐库不自动上传。一键分享使用 Cloudflare 隧道代理访问，详情见 [多人房间说明.md](多人房间说明.md)。单人数据存储如下：

| 数据 | 存储位置 | 清除方式 |
|---|---|---|
| 音乐库中的本地文件 | IndexedDB 库 `mikuFocusDB` | 音乐库中逐首删除 / 清空本地导入 / 清除站点数据（底部列表 ✕ 只移出队列） |
| 网易云来源歌单 / 最近输入的歌单链接 | localStorage `mikuFocusMusicLibrary_v2` / `mikuFocusNeteaseLink` | 音乐库中删除 / 清除浏览器站点数据；旧键 `mikuFocusNetease_v1` 仅作迁移备份，不会重新加入已删除收藏 |
| 已记住的网易云登录 | Windows 当前用户的 `%LOCALAPPDATA%\MikuFocus\auth\netease-sessions.dpapi` 加密文件 | 退出登录 / 取消记住；清除浏览器数据只移除浏览器标识，不会主动删除服务电脑中的记录，记录到期后失效 |
| 当前个人播放列表 | localStorage `mikuFocusPlayQueue_v1` | 播放列表中移除或清空 |
| 待办事项 | localStorage 键 `mikuFocusTodos_v1` | 待办面板里逐条 ✕，或清除浏览器站点数据 |
| 任务累计时长 / 最近选择的任务 | localStorage `mikuFocusTaskFocus_v1` / `mikuFocusSelectedTask_v1` | 清除浏览器站点数据 |
| 背景选择与轮换 / 省性能设置 | localStorage `mikuFocusBackground_v1` | 背景设置中修改，或清除浏览器站点数据 |
| 复制到项目的自选背景 | `app/assets/images/custom-*` 与 `custom-backgrounds.js` | 属于项目素材；不会因为清除浏览器数据而删除 |
| 离线/远程页面导入的背景 | IndexedDB `mikuFocusBackgrounds` / `images` | 清除该网址的浏览器站点数据；不包含在项目分享包内 |
| 未结束的计时快照 | localStorage 键 `mikuFocusRun_v1` | 计时段结束后自动清除 |
| 每日专注统计 | localStorage 键 `mikuFocusStats_v1` | 同上 |
| 音量设置 | localStorage 键 `mikuFocusVol` | 同上 |

## 常见问题

- **刷新后歌单还在吗？** 在。Chrome/Edge 下自动恢复；Firefox 打开本地文件（file://）时数据库受限，会自动退回"仅本次会话有效"，其余功能不受影响。
- **换电脑/换浏览器后歌单和统计没了？** 这些数据按浏览器存储，不跟随文件，需要重新导入。
- **素材版权**：壁纸插画与视频均来自你自己的 Wallpaper Engine 素材（工程包 / 订阅内容提取），仅供个人本地使用，请勿商用或二次分发。
